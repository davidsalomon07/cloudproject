Idea 3: Sistema de Monitoreo de Servidores y Alertas en Tiempo Real (Herramienta DevOps)
¿De qué trata? Una mini plataforma web que simula revisar el estado de salud de otros servidores o páginas web (si están online u offline) y muestra las alertas en un panel gráfico.

¿Cómo se lucen con los puntos de la pizarra?

Orquestación Completa: Es una idea perfecta para Docker porque la naturaleza del proyecto es de infraestructura. Tienen el Front (gráficos del estado de los servidores), el Back (el que hace los chequeos concurrentes) y la BDD (el histórico de caídas).

Diagnóstico de Conectividad: Esta idea mata dos pájaros de un tiro. Como el proyecto en sí mismo trata de conectividad, los paneles de diagnóstico que le mostrarán al profesor serán parte de la misma aplicación, usando herramientas del sistema operativo metidas dentro de los contenedores.

Gestión de Credenciales: Ideal para demostrar cómo protegen las APIs externas (por ejemplo, si integran un bot de Discord o Telegram que avise cuando un servidor se cae) usando variables ocultas en el entorno de Docker.
